CBSOM: Compositional Binding with Self-Organizing Maps

Amir Ozhan Dehghani, Blake Richards
📄 Paper 💻 Code ⬇️ PDF

Abstract

In order to generalize combinatorially, neural systems must be able to flexibly and dynamically bind object representations with other attributes. While recent work has made progress using vector symbolic architectures (VSAs), these techniques often depend on operations such as circular convolution or matrix multiplication, which are difficult to implement in biological circuits. Here we introduce CBSOM, a model for compositional binding that uses self-organizing maps (SOMs) and Hebbian plasticity to learn representations that bind in a biologically plausible manner. We demonstrate that CBSOM enables generalization in analogy and rule-based tasks, and provides insight into how brains might implement compositional generalization.
